Consequências para o desenho (decisão do orquestrador, a validar pelo crítico):
- Exploração "funcionalidade por funcionalidade" usa por padrão `npx playwright cli`, da mesma versão fixada do `@playwright/test` do projeto ou do harness. O MCP fica como alternativa quando já estiver configurado; nunca `@latest`.
- Browser: com Chrome ou Edge na máquina, use `channel: 'chrome'` ou `msedge` na config e `--browser=chrome` no CLI, sem download. Sem eles, `npx playwright install chromium` baixa o browser para o cache do usuário: avise o tamanho. `install-deps` e `--with-deps` exigem sudo/admin e só rodam com confirmação.
