# Avaliação da skill QA

Método: `../references/ia-e-llm.md`. Guarde versão, pedido/contexto bruto,
resposta integral, rubrica predefinida, evidência, revisão e alteração apoiada
na falha observada. Separe desenvolvimento e validação ainda não usada para
editar instruções. Revisão por IA não equivale a julgamento humano.

`../tests/` verifica helpers; isso não mede sozinho qualidade de respostas
de um modelo usando a skill. Um caso projetado não é avaliação executada.
